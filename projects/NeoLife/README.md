# NeoLife

**Marka ve içerik** · Proje incelemesi

Gayrimenkul projeleri, hizmetler ve editoryal içerikleri Türkçe sunan çok sayfalı, responsive marka sitesi.

## Teknoloji

HTML · CSS · JavaScript · Bootstrap · Swiper · GSAP · Node.js yayın araçları

## Mimari akış

İçerik → statik sayfalar → proje keşfi → WhatsApp bilgi talebi

## Mühendislik odağı

- Üretim paketinde temiz URL, canonical, JSON-LD ve sitemap üretilir.
- Yerel etkileşim kitaplıkları çok sayfalı statik yapıyı destekler.
- WhatsApp talep başlangıcı ölçümü ziyaretçi onayına bağlı olarak ele alınır.

## Kapsam ve sınırlar

Ayrı uygulama sunucusu veya veritabanı yoktur; WhatsApp talebi tamamlanmış satış veya CRM kaydı değildir.

Teknik özet mevcut proje dokümantasyonundan hazırlanmıştır. Bu vitrin kapsamında uygulama çalıştırma veya canlı ortam kabulü yapılmamıştır.
