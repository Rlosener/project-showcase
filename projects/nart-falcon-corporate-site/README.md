# NART FALCON — Kurumsal Site

**Marka ve içerik** · Proje incelemesi

Hizmetleri, yaratıcı alanları, içerikleri ve iletişim akışını koyu zemin ve lime marka vurgusuyla sunan kurumsal web projesi.

## Teknoloji

HTML · CSS · JavaScript · PHP 8.1+ · Apache/cPanel

## Mimari akış

Kurumsal içerik → responsive sayfalar → doğrulanan iletişim formu → posta servisi

## Mühendislik odağı

- Ortak gezinme ve marka stilleri çok sayfalı deneyimi bir arada tutar.
- PHP formunda sunucu doğrulaması, CSRF, honeypot ve gönderim sınırı bulunur.
- Statik sunum ile iletişim uç noktası farklı çalışma sorumlulukları taşır.

## Kapsam ve sınırlar

E-posta teslimi hosting posta servisine bağlıdır; bu kurumsal proje tek başına mağaza backend’i içermez.

Teknik özet mevcut proje dokümantasyonundan hazırlanmıştır. Bu vitrin kapsamında uygulama çalıştırma veya canlı ortam kabulü yapılmamıştır.
