# Kontrollü DOM Analiz Uygulaması

**Otomasyon araçları** · Proje incelemesi

Açık tarayıcı penceresindeki görünür liste içeriklerini inceleyen, filtreleyen ve kontrollü işlemler sunan masaüstü uygulaması.

## Teknoloji

Python · Tk/Tcl · masaüstü tarayıcı otomasyonu · CSV

## Mimari akış

Görünür liste → kontrollü tarama → sonuç tablosu → filtreleme → dışa aktarma

## Mühendislik odağı

- Sanal listelerde kaydırma ile yeni görünen kayıtlar biriktirilir.
- Bekletme, sürdürme ve durdurma kontrolleri tarama durumunu operatöre açar.
- İşlem geçmişi ve sonuç dışa aktarma, tarama ile sonraki işlemleri izlenebilir tutar.

## Kapsam ve sınırlar

Yalnızca görünür ve desteklenen içerikle çalışır; özel veya erişilemeyen verilere erişim iddiası yoktur.
