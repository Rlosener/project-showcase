# Nart Falcon Platform

**Web ürünleri** · Proje incelemesi

Kurumsal site ile ürün yönetimi ve WhatsApp sipariş talebini ayrı yayın hedeflerinde birleştiren monorepo.

## Teknoloji

HTML/CSS/JavaScript · React · TypeScript · Vite · PHP · MySQL

## Mimari akış

Kurumsal vitrin → mağaza → ürün / ölçü / renk → sepet → WhatsApp talebi

## Mühendislik odağı

- Kurumsal site ve mağaza ayrı uygulamalar olarak aynı depoda düzenlenir.
- Ölçüye bağlı fiyat farkı ve varyant seçimi ürün akışının parçasıdır.
- PHP/MySQL katmanı mağaza veri yönetimini istemci sunumundan ayırır.

## Kapsam ve sınırlar

MVP’de online ödeme, müşteri hesabı, stok ve sipariş takip sistemi yoktur; sohbet açılması tamamlanmış satış değildir.

Teknik özet mevcut proje dokümantasyonundan hazırlanmıştır. Bu vitrin kapsamında uygulama çalıştırma veya canlı ortam kabulü yapılmamıştır.
