# Aura In Cyprus

**Marka ve içerik** · Proje incelemesi

Gayrimenkul, bölge rehberleri ve iletişim içeriklerini Türkçe sunan, mevcut tema üzerine marka katmanı eklenmiş web sitesi.

## Teknoloji

HTML · CSS · JavaScript · PHP

## Mimari akış

Tema bileşenleri → Aura marka katmanı → ilan / rehber sayfaları → iletişim formu

## Mühendislik odağı

- Markaya özgü görünüm ve etkileşim katmanı mevcut tema bileşenlerinden ayrılır.
- Çok sayfalı düzen ilan keşfi ve bölge içeriklerini ortak gezinmede toplar.
- İletişim uç noktası alan doğrulaması ile sunucu posta yapılandırmasını birlikte ele alır.

## Kapsam ve sınırlar

Yerel sayfa önizlemesi e-posta teslimini veya canlı hosting kabulünü kanıtlamaz.

Teknik özet mevcut proje dokümantasyonundan hazırlanmıştır. Bu vitrin kapsamında uygulama çalıştırma veya canlı ortam kabulü yapılmamıştır.
