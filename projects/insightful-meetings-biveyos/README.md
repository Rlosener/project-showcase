# Insightful Meetings / Biveyos

**Web ürünleri** · Proje incelemesi

Toplantı ve mülakat kayıtları, transkriptler, analizler ve raporlar etrafında kurulan React web uygulaması.

## Teknoloji

React 18 · TypeScript · Vite · Tailwind · Radix/shadcn · Supabase

## Mimari akış

Kayıt → Storage → sunucu işlemleri → transkript / analiz → rapor

## Mühendislik odağı

- Supabase Auth, Postgres ve Storage kimlik, veri ve medya sorumluluklarını paylaşır.
- Edge Functions sunucu işlemlerini tarayıcı arayüzünden ayırır.
- Kurumsal toplantı ve bireysel mülakat deneyimleri farklı kullanıcı hedeflerine göre düzenlenir.

## Kapsam ve sınırlar

Gerçek özellikler etkin Supabase işlevlerine ve sağlayıcı ayarlarına bağlıdır; AI yorumları kesin gerçek değildir.

Teknik özet mevcut proje dokümantasyonundan hazırlanmıştır. Bu vitrin kapsamında uygulama çalıştırma veya canlı ortam kabulü yapılmamıştır.
