# Biveyos Interview Console

**Native uygulamalar** · Proje incelemesi

Aday havuzu ve mülakat ekranlarını masaüstü çalışma alanında birleştiren Python uygulaması.

## Teknoloji

Python · Tkinter/CustomTkinter · JSON · PDF ve ses işleme modülleri

## Mimari akış

Örnek aday havuzu → aday profili → mülakat ekranı

## Mühendislik odağı

- Aday kartı, profil özeti ve görüşme alanı ayrı bilgi katmanları olarak düzenlenir.
- JSON demo kayıtları aday akışının örneklenmesini sağlar.
- PDF, ses ve görüntü modülleri uygulamanın teknik bağımlılıkları arasında yer alır.

## Kapsam ve sınırlar

Demo veri yüklenmesi, canlı veritabanı veya AI sağlayıcı entegrasyonunun çalıştığını kanıtlamaz.

Teknik özet mevcut proje dokümantasyonundan hazırlanmıştır. Bu vitrin kapsamında uygulama çalıştırma veya canlı ortam kabulü yapılmamıştır.
